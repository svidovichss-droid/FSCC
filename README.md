# DataMatrix Quality Scanner

Сканер качества печати DataMatrix согласно стандарту ISO 15415 для промышленных систем контроля качества.

## Возможности

- **ISO 15415**: Оценка качества DataMatrix по международному стандарту
- **Промышленная камера**: Поддержка высокоскоростных USB3/GigE камер для конвейерных систем
- **Веб-камера**: Режим ручной проверки с обычной веб-камерой
- **Звуковые оповещения**: Зоны D и F с предупреждающими звуковыми сигналами
- **История сканирований**: Сохранение результатов в локальной базе данных
- **Автоопределение**: Распознавание квадратов, не являющихся DataMatrix, как оценка F

## Системные требования

- Windows 10/11 (x64)
- Камера с поддержкой USB Video Class (UVC)
- 4 ГБ ОЗУ
- 500 МБ свободного места на диске

## Установка

### Готовый EXE файл

Загрузите последнюю версию со страницы [Releases](https://github.com/YOUR_USERNAME/datamatrix-scanner/releases/latest):

```
DataMatrixQualityScanner-1.0.0-portable.exe
```

### Сборка из исходного кода

1. Клонируйте репозиторий:
```bash
git clone https://github.com/YOUR_USERNAME/datamatrix-scanner.git
cd datamatrix-scanner
```

2. Установите зависимости:
```bash
pnpm install
```

3. Соберите приложение:
```bash
pnpm run build
pnpm run electron:build
```

4. Исполняемый файл будет находиться в директории `release/`

## GitHub Actions

Репозиторий настроен для автоматической сборки Windows EXE через GitHub Actions.

### Автоматическая сборка

При каждом push в ветку `main` или создании тега `v*` запускается процесс сборки:

1. Устанавливаются зависимости Node.js и pnpm
2. Собирается React приложение
3. Собирается Electron приложение
4. Создается портативный EXE файл
5. Артефакты загружаются в раздел Actions

### Ручной запуск сборки

1. Перейдите на вкладку **Actions** в репозитории GitHub
2. Выберите workflow **Build Windows EXE**
3. Нажмите **Run workflow**
4. Выберите ветку и запустите сборку

### Скачивание артефактов

После успешной сборки:

1. Перейдите на вкладку **Actions**
2. Выберите завершенный workflow
3. Нажмите на название коммита
4. В секции **Artifacts** скачайте `DataMatrixQualityScanner-win-x64`

## Классы качества ISO 15415

| Класс | Диапазон | Описание |
|-------|----------|----------|
| A | ≥ 3.5 | Отлично |
| B | ≥ 2.5 | Хорошо |
| C | ≥ 1.5 | Приемлемо |
| D | ≥ 0.5 | Предупреждение |
| F | < 0.5 | Брак |

## Параметры оценки

- **SC** (Symbol Contrast) - контраст символа
- **C** (Cell Decode) - декодируемость ячеек
- **M** (Modulation) - модуляция
- **MR** (Reflectance Margin) - запас отражения
- **FP** (Finder Pattern Damage) - повреждение искателя
- **AN** (Axial Non-Uniformity) - осевая неоднородность
- **GN** (Grid Non-Uniformity) - растровая неоднородность
- **UEC** (Unused Error Correction) - неиспользованная коррекция ошибок

## Режимы камеры

### Промышленная камера
- Высокоскоростное считывание с конвейера
- Настраиваемая экспозиция и усиление
- ROI (область интереса)
- Компенсация скорости линии

### Веб-камера
- Ручная проверка
- Мгновенное переключение режимов
- Портативность
